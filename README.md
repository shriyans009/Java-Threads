# Java-Threads

## Description

This project demonstrates the working of **threads** in Java using multiple `.java` files. It includes custom implementations of `Runnable` to show different operations running concurrently.

## Features

- Demonstrates thread creation using `Runnable` interface.
- Each operation is encapsulated in a separate class/function.
- Includes comments and coding best practices.
- Uses multiple `.java` files to show modular programming.

## Files

- `Main.java`: Entry point of the program. Creates and starts multiple threads.
- `MyThread.java`: Implements the `Runnable` interface to perform arithmetic operations with delay.
- `ThreadOperations.java`: *(Optional)* Provides reusable thread operations like printing squares or even numbers.
